# Beranda — Page Override

Read `../MASTER.md` first. This file only documents homepage-specific rules.

## Objective
Explain SLF to a first-time visitor, establish trust, then guide them to connect to the server or read essential information.

## Structure
1. Hero: concise identity statement, one-sentence value proposition, primary **Mulai Bermain** CTA.
2. Quick navigation: connect, zones, rules, Wiki, community.
3. Feature/zone cards: Green, Yellow, Red (and Black only if actually active/published).
4. Server features and gameplay rules: factual, concise, no invented features.
5. Store preview and recent announcements.
6. Community/social links and help.

## Visual rules
- Keep the established navy/cyan/lavender portal atmosphere.
- Hero may use radial gradients and restrained geometric portal motif; no heavy animation or video background.
- Make Java and Bedrock connection instructions easy to distinguish and copy.
- Use one primary CTA; secondary actions remain visually quieter.
- Keep cards consistent with the existing 13–17px radius and quiet border system.

## Interaction and content
- Copy buttons need visible copied/error feedback.
- Announcements need loading, empty, and error states; do not silently hide a failed feed.
- Don't label a server status as live unless it comes from a current server source.
- Test at 320, 375, 414, 768, 1024, and 1440px.
