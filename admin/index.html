Memeriksa konfigurasi…

Owner

Pemilik penuh: kas/keuangan, editor website, produk, promo, laporan, dan semua operasional.

Admin / staf

Operasional terbatas: menangani pesanan/tiket, ulasan, pelanggan, pengumuman, catatan tim, dan aktivitas. Tidak bisa membuka keuangan, mengubah harga/promo, atau mengedit slot/kartu website.

Cara mengaktifkan dua role

  1. Cloudflare Dashboard → Workers & Pages → proyek SLF → Settings → Variables and Secrets.
  2. Atur OWNER_SECRET khusus Owner dan ADMIN_SECRET khusus staf. Keduanya wajib berbeda dan minimal 32 karakter acak.
  3. Atur juga TICKET_LINK_SECRET untuk membuat kunci privat tiap tiket re-entry. Harus minimal 32 karakter acak dan berbeda dari dua secret role.
  4. Simpan konfigurasi di Cloudflare Pages → Settings → Variables and Secrets. Jika secret baru ditambahkan, deploy ulang bila diperlukan. Jangan kirim rahasia lewat grup publik.
  5. Jika OWNER_SECRET belum disetel, login sengaja dikunci; tidak ada mode lama yang menjadikan ADMIN_SECRET sebagai Owner.

Tidak ada mode kompatibilitas: login dikunci sampai OWNER_SECRET dan ADMIN_SECRET tersedia, berbeda, dan masing-masing minimal 32 karakter acak. Setelah konfigurasi Cloudflare disimpan, buka ulang panel dan login memakai rahasia role yang sesuai.
