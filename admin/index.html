Simulasi rencana pendanaan

Area ini hanya kalkulator/draf internal Owner, bukan toko atau pendaftaran investor. Tidak ada pembayaran, janji hasil, atau penawaran publik dari tool ini.

DRAF INTERNAL SAJA — belum ada pembelian, pendaftaran pemodal, pencatatan lembar anggota, atau pembayaran. Jangan menerima uang anggota atau mengumumkan penawaran sampai wali dan profesional hukum/keuangan memeriksa struktur, perizinan, kontrak, dan pajaknya.

Ketentuan draf yang perlu disepakati

  • Siklus pembagian direncanakan setiap 4 bulan sejak tanggal mulai resmi.
  • Snapshot laporan keuangan direncanakan diumumkan 2 hari sebelum jadwal pembagian.
  • Modal masuk pada 1–2 bulan pertama ikut secara proporsional menurut bulan aktif / 4. Modal yang baru masuk setelah 3 bulan siklus berjalan tidak ikut pembagian terdekat dan menunggu periode berikutnya untuk ikut penuh.
  • Pembagian hanya dipertimbangkan jika ada laba bersih yang tersedia. Jika tidak ada laba, tidak ada pembayaran pada periode itu; evaluasi lagi pada periode berikutnya.
  • Keikutsertaan sukarela tanpa paksaan. Jika server tutup/bangkrut, pengembalian modal tidak dijamin penuh dan dapat sebagian atau tidak ada.
  • Jumlah lembar anggota baru dapat dicatat/dilihat melalui akun pribadi setelah mekanisme legal, perlindungan data, dan pembelian disetujui. Saat ini semuanya masih draf dan tidak menerima pembayaran.

Pemisahan akses Owner dan Admin

Hak akses diperiksa di server API, bukan hanya menyembunyikan tombol di browser.

Memeriksa konfigurasi…

Owner

Pemilik penuh: kas/keuangan, editor website, pengaturan draf pendanaan, produk, promo, laporan, dan semua operasional.

Admin / staf

Operasional terbatas: menangani pesanan/tiket, ulasan, pelanggan, pengumuman, catatan tim, dan aktivitas. Tidak bisa membuka keuangan, mengubah harga/promo, atau mengedit slot/kartu website.

Cara mengaktifkan dua role

  1. Cloudflare Dashboard → Workers & Pages → proyek SLF → Settings → Variables and Secrets.
  2. Tambahkan rahasia OWNER_SECRET khusus Owner dan rahasia berbeda ADMIN_SECRET untuk staf. Gunakan rahasia panjang acak (minimal 32 karakter), bukan PIN enam digit.
  3. Simpan lalu redeploy/restart sesuai instruksi Cloudflare. Jangan kirim rahasia lewat grup publik.
  4. Setelah OWNER_SECRET aktif, ADMIN_SECRET otomatis menjadi role Admin terbatas.

Mode kompatibilitas: jika OWNER_SECRET belum tersedia, ADMIN_SECRET lama masih berfungsi sebagai Owner. Atur rahasia Owner terlebih dahulu sebelum membagikan rahasia Admin.

Jaga rahasia Owner dan Admin. Jangan pernah membagikannya di chat publik.
